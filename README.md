# SkinVote — Desktop Application

Десктопное оффлайн-приложение на базе **Electron** для визуального 3D-просмотра и субъективной оценки скинов Minecraft.

Работает **100% автономно** без подключения к интернету: скины обрабатываются локально на компьютере, 3D-модели рендерятся через WebGL, а все шрифты и библиотеки встроены в дистрибутив.

---

## 🚀 Быстрый старт и запуск

### Требования
- **Node.js**: версия 18.x, 20.x или 22.x (LTS рекомендуется)
- **npm**: версия 9.x или новее

### Установка зависимостей
```bash
npm install
```

### Запуск в режиме разработки (десктоп)
```bash
npm start
```

---

## 📦 Сборка в .EXE (Windows)

Для сборки автономного исполняемого файла выполните команду:

```bash
npm run dist
```

Эта команда сгенерирует в папке `dist/`:
1. **Инсталлятор (NSIS)**: `dist/SkinVote-Setup-1.0.0.exe` — установщик с возможностью выбора директории, созданием ярлыков на рабочем столе и в меню «Пуск».
2. **Портативная версия (Portable)**: `dist/SkinVote-Portable-1.0.0.exe` — единый `.exe` файл, не требующий установки (можно запускать с флешки или из любой папки).

### Дополнительные команды сборки
- `npm run dist:portable` — собрать только Portable `.exe`
- `npm run dist:nsis` — собрать только NSIS установщик `.exe`
- `npm run dist:dir` — собрать распакованную папку приложения (`dist/win-unpacked/`)
- `npm run setup-assets` — перегенерировать иконки (.ico / .png) и шрифты из исходников

## ✨ Возможности приложения

- **Полная оффлайн-работа**: никаких внешних запросов к Google Fonts, CDN или удалённым серверам.
- **Drag-and-Drop**: перетаскивание папок со скинами или отдельных PNG-файлов прямо в окно программы.
- **3D-модель Minecraft**: интерактивный просмотр (вращение ЛКМ, перемещение ПКМ, зум колесом мыши) на базе `skinview3d` и `three.js`.
- **Автоопределение и переключение моделей**: поддержка Slim (Alex) и Wide (Steve), а также классических `64×32` и HD-скинов (`128×128`, `256×128` и т.д.).
- **5 категорий оценки**: Красный цвет, Синий цвет, Логотип спереди, Лого взади, Линзы (шкала 1–10 с мгновенным подсчётом среднего).
- **Интеллектуальный тейбрейкер**: при равенстве баллов в топ-8 скины сравниваются попарно («какой лучше?»), что определяет справедливый порядок в таблице лидеров без изменения баллов.
- **Таблица лидеров и Подиум Топ-3**: с 3D-превью, сортировкой по любой категории и гибкими фильтрами (поиск, диапазон баллов).
- **Интеграция с проводником Windows**: в десктопной версии кнопка «Расположение файла» позволяет мгновенно открыть и выделить файл в Проводнике (`Explorer`) в 1 клик.
- **Экспорт и импорт оценок**: сохранение всей сессии в `.json` и загрузка сохранённых результатов с превью.

## 🛠 Архитектура и список изменений относительно веб-сайта

### 1. Выбор платформы: Electron
- **Обоснование**: Приложение активно использует WebGL (шейдеры Three.js / skinview3d), Canvas 2D для анализа пикселей (автоопределение Slim/Wide) и современные ES-модули. Electron предоставляет полноценную предсказуемую среду Chromium и Node.js API, гарантируя одинаковый рендеринг на любых версиях Windows без зависимости от установленной версии системного WebView2.

### 2. Локализация всех внешних зависимостей
- **Шрифты**: Google Fonts (`Manrope` 400–800 и `Outfit` 500–800) скачаны и локализованы в формате WOFF2 в папке `assets/fonts/`. Подключение осуществляется через локальный `assets/fonts/fonts.css`.
- **Безопасность (CSP)**: Добавлена строгая политика Content Security Policy (`default-src 'self' ... connect-src 'self' blob: data:`), полностью запрещающая любые сетевые запросы во внешнюю сеть.

### 3. Иконки приложения
- Из оригинального SVG-логотипа (`assets/favicon.svg`) сгенерирован полноценный Windows multi-size `.ico` файл (`assets/icon.ico`), содержащий размеры: `16×16`, `32×32`, `48×48`, `64×64`, `128×128`, `256×256`, а также PNG-иконки высокого разрешения (`512×512`).
- Иконка подключена к окну приложения, панели задач и исполняемому файлу `.exe`.

### 4. Нативная интеграция с ОС (IPC)
- Добавлен `preload.js` с безопасным `contextBridge` (`nodeIntegration: false`, `contextIsolation: true`).
- Реализована функция `shell.showItemInFolder`: в окне «Расположение файла» появилась нативная кнопка **«Показать в проводнике»**, которая выделяет скин в проводнике Windows.

### 5. Адаптивность и поведение окна
- Настроены минимальные размеры окна (`960×640`) и стартовое разрешение `1280×820`.
- Добавлены адаптивные стили для мониторов разного разрешения (от компактных ноутбуков до 4K/Ultrawide) и экранов с малой высотой (`@media (max-height: 720px)` с плавной вертикальной прокруткой).

## 📋 Структура проекта

```
SkinVote-Program/
├── assets/
│   ├── favicon.svg          # Исходный векторный логотип
│   ├── icon.ico             # Windows multi-size иконка (16–256px)
│   ├── icon.png             # Иконка приложения (512×512)
│   └── fonts/               # Локальные WOFF2 шрифты Manrope и Outfit
│       └── fonts.css        # Локальные @font-face стили
├── css/
│   └── app.css              # Стили приложения (адаптивная верстка, темная тема)
├── js/
│   ├── app.js               # Главная логика UI, рейтингов и таблицы лидеров
│   ├── files.js             # Валидация PNG, File System API, определение модели
│   └── viewer.js            # 3D-вьюер скинов на базе skinview3d / three.js
├── vendor/
│   └── skinview3d.bundle.js # Локальный бандл 3D-движка skinview3d
├── scripts/
│   └── setup-assets.mjs     # Скрипт сборки ассетов (иконки, шрифты)
├── index.html               # Главная разметка приложения (оффлайн CSP)
├── main.js                  # Главный процесс Electron (BrowserWindow, меню, IPC)
├── preload.js               # Безопасный мост между Electron и Renderer
├── package.json             # Зависимости и конфигурация electron-builder
└── README.md                # Документация проекта
```

## 🔒 Безопасность и оффлайн-гарантии

- Отключена интеграция Node.js в Renderer (`nodeIntegration: false`)
- Включена изоляция контекста (`contextIsolation: true`)
- Включен Sandbox (`sandbox: true`)
- Запрещена навигация на внешние сайты внутри окна приложения (при необходимости ссылки открываются в системном браузере по умолчанию)
- Запросы к сети отсутствуют: все ресурсы упакованы локально
